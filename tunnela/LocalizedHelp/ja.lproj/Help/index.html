tunnela

拠点の異なる2台のMac間で、SSHポートフォワーディングによるポートアクセスを実現するためのSSHトンネル構成を支援するアプリです。 各拠点のMacに固定IPアドレスやポート開放は不要です。 双方からSSH接続ができる中継サーバーがあれば動作します。

SSHトンネルおよびポートフォワードの基礎知識がある方向けです。

仕組み

ホスト 側のMacが中継サーバーへリバーストンネルを張ります:
ssh -R <内部ポート>:localhost:22 user@中継

クライアント 側のMacが中継経由でホストに接続します:
ssh -L <ローカルポート>:localhost:<内部ポート> user@中継

接続後、クライアントから localhost:<ローカルポート> でホストのSSHに到達できます。サービス転送を追加すれば、VNCやHTTPなど任意のポートにも同様にアクセスできます。

ホストの設定

項目説明
アドレス中継サーバーのホスト名またはIPアドレス
SSHポート中継サーバーのSSHポート（通常は22）
ユーザー名中継サーバーへのSSHログインユーザー名
認証方法中継サーバーへの認証（SSH鍵またはパスワード）
内部ポート中継サーバー上に確保する仮想ポート（例: 22222）。共有サーバーでは他ユーザーと被らない番号を選ぶ
このMacのSSHポートリバーストンネルが転送先とするこのMacのSSHポート（通常は22）

クライアントの設定

中継サーバー

アドレス・内部ポート・ユーザー名・認証はホスト側と同じ値を使います。

項目説明
ローカルポートこのMacで中継トンネルを受け取るポート（例: 22222）。ホストへの接続時に -p として使われます

ホストへの接続

項目説明
ユーザー名ホスト側MacへのSSHログインユーザー名
認証方法ホスト側Macへの認証（SSH鍵またはパスワード）

サービス転送

登録した各エントリが、中継トンネル経由でホストの特定ポートへの ssh -L フォワードを作成します。 接続中でもホットで追加・削除できます。

項目説明
ホストのポートホスト側で転送したいポート（例: VNCなら 5900）
このMacのポートこのMacで待ち受けるポート（例: 55900）

SOCKS5プロキシ

中継トンネル経由で ssh -D <ポート> を実行し、ホスト側ネットワークへのSOCKS5プロキシを提供します。 ブラウザやシステムプロキシで localhost:<ポート> を指定して使います。
