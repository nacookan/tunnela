tunnela

tunnela helps configure SSH tunnels for SSH port forwarding between two Macs at different locations. Neither Mac needs a fixed IP address or open ports — a relay server that both Macs can SSH into is all that's required.

Intended for users familiar with SSH tunnels and port forwarding.

How It Works

The Host Mac opens a reverse tunnel to the relay:
ssh -R <internal-port>:localhost:22 user@relay

The Client Mac connects through the relay to reach the Host:
ssh -L <local-port>:localhost:<internal-port> user@relay

The Client can then reach the Host's SSH at localhost:<local-port>. Adding service forwards extends this to any other port on the Host — VNC, HTTP, and so on.

Service Forwards

Each entry creates an additional ssh -L forward through the relay tunnel to a specific port on the Host. Forwards can be added or removed while a connection is active.

FieldDescription
Host PortPort on the Host to forward (e.g. 5900 for VNC)
This Mac's PortLocal port to listen on (e.g. 55900)

SOCKS5 Proxy

Runs ssh -D <port> through the relay tunnel, providing a SOCKS5 proxy to the Host's network. Configure your browser or system proxy to use localhost:<port>.
